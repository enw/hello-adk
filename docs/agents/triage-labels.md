# Triage labels

Canonical roles and local Status values are identical:

| Role / Status | Meaning |
| --- | --- |
| needs-triage | Maintainer must evaluate |
| needs-info | Waiting for more information |
| ready-for-agent | Fully specified; agent can implement |
| ready-for-human | Requires human implementation |
| wontfix | Will not be actioned |

Use these values when a skill requests a triage label.
